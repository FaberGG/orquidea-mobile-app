# Componentes de contenido

Pantallas y piezas visuales de HE-06. `AnnouncementsListScreen` muestra HU-17 con sus estados de
carga, error, lista vacía y actualización; `AnnouncementCard` presenta cada anuncio completo.
`CreateAnnouncementButton` es el "+" del encabezado de Anuncios para publicar uno nuevo (HU-16, Acta 17).
