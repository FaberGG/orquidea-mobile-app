# docs/conventions/

Reglas **obligatorias** del equipo. Se verifican en la revisión de cada PR y, cuando es posible, con herramientas automáticas.

| Documento | Contenido |
|---|---|
| [CODIGO.md](CODIGO.md) | TypeScript, nombres, imports, componentes, estilos, accesibilidad, datos, errores, seguridad, pruebas |
| [GIT.md](GIT.md) | Modelo de ramas, nombres de ramas, Conventional Commits, Pull Requests, versionado |

Para proponer un cambio a una convención: PR `docs(conventions): ...` con la justificación; requiere acuerdo del equipo.
