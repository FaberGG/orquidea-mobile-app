# docs/requirements/

Requisitos funcionales del producto, definidos con el comité del humedal.

- [`Historias-Usuario.md`](Historias-Usuario.md): 8 épicas (HE-01 a HE-08), historias de usuario (HU) y
  criterios de aceptación en formato Contexto / Evento / Resultado esperado.

## Cómo se usan

- Cada rama, issue y PR referencia la HU que implementa (`HU-7`).
- Los **mensajes** de los criterios de aceptación son textuales y se copian tal cual al código
  (ver [CODIGO.md §9](../conventions/CODIGO.md#9-formularios-y-mensajes)).
- Los diseños (Figma) se enlazarán aquí o en cada HU cuando estén disponibles.
- Los cambios a una HU se acuerdan con el Product Owner y se registran en este archivo vía PR (`docs(requirements): ...`).
